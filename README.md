# Karla Alvarez Personal Webpage

A sleek and interactive personal webpage showcasing Karla's hobbies: Music, Poetry, Reading, LEGO, and Documentaries.

## Features
- Dark/Light mode toggle
- Glass morphism design with subtle gradients
- Animated hobby cards
- Embedded YouTube video
- Responsive layout

## Usage
1. Open `index.html` in a web browser.
2. Replace `placeholder.jpg` with your actual photo.
3. Customize styles in `style.css` or add interactivity in `script.js`.

## Troubleshooting
- If the page doesn't load, ensure all files are in the same directory.
- For photo issues, use a valid image URL or local path.

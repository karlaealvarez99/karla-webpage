My Projects

  • 🏁 CSN150 Final Project: Storm Breaker: For my final project in CSN150, I decided to dive deep into Storm Breaker, a social engineering tool that honestly blew my mind when I first learned about it. The tool can access webcams, listen through microphones, track location, grab passwords, and pull device information—all through phishing links. It was eye-opening to see how effective social engineering can be compared to just hacking systems directly.
    • File: Final_KA.pdf
    • Link: Open PDF
  • 🛡️ Project #2: NBA Machine Learning Sports Betting: This was legitimately fun. I wanted to see if I could use machine learning to predict NBA game outcomes, so I built a project that uses AI to calculate win/loss percentages for teams. Before this, machine learning felt abstract. But actually building something that makes predictions and seeing it work (or fail) made the whole thing click for me. I also got way better at troubleshooting dependency issues and managing Python environments.
    • File: NBABet_KA.pdf
    • Link: Open PDF
  • 🔒 Project #3: Lockbit Presentation: I created a presentation on LockBit because I wanted to understand how one of the most dangerous hacker groups actually operates. LockBit runs a ransomware-as-a-service business—basically they sell malware to other criminals. It's wild how organized they are. I did a ton of research, put together the PowerPoint, and actually recorded myself going through it to make sure I could explain it clearly. Presenting this stuff made me realize how much I still need to learn about cybersecurity, but also how much I've already picked up.
    • File: Lockbit_KA 1.pptx
